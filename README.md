# PaketDepo - Toptan Ambalaj & B2B E-Ticaret Platformu

PaketDepo, endüstriyel gıda ambalajları ve tek kullanımlık kurumsal sarf malzemeleri tedariği sağlayan modern bir B2B & B2C e-ticaret web uygulamasıdır.

## 🚀 Teknolojik Altyapı

- **Frontend & Framework:** React 19, TypeScript
- **Yönlendirme & Veri Yönetimi:** TanStack Router & TanStack Query
- **Stil & Tasarım Sistemi:** Tailwind CSS v4, Radix UI bileşenleri, Lucide ikon seti
- **Derleme Aracı:** Vite

## 📦 Temel Özellikler

- **Geniş Ürün Kataloğu:** Sıcak/soğuk karton bardaklar, PET ürünler, sızdırmaz çorba kapları ve hijyen ambalajları.
- **Kademeli Fiyatlandırma:** Koli ve palet bazlı otomatik iskonto hesaplama motoru.
- **Kurumsal B2B Fonksiyonları:**
  - Hızlı Excel ile toplu sipariş yükleme
  - Ücretsiz numune talep formu
  - Gerçek zamanlı stok durumu ve koli birim maliyet gösterimi
- **Duyarlı Tasarım:** Mobil, tablet ve masaüstü ekranlar için optimize edilmiş arayüz.

## 🛠️ Yerel Geliştirme (Local Development)

Projeyi yerel ortamınızda çalıştırmak için:

```sh
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Projeyi üretim için derleyin
npm run build
```

Yerel önizleme: `http://localhost:8080/`
